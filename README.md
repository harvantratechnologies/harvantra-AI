# Harvantra AI

AI-assisted business discovery and client acquisition CRM.

## Features

- Free OpenStreetMap business discovery
- Overpass API integration
- Nominatim location search
- 30 Harvantra service categories
- Personalized email and WhatsApp drafts
- SQLite CRM
- Lead status tracking
- CSV import and export
